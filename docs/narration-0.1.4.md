# 0.1.4 解説口調の見直し（2026-10-22）

共通要件12・73・74と `../work/NARRATION_ADDONS_PLAN.md` を確認し、字幕・要約・アイテム説明・章の説明を全22言語で推敲しました。語尾の一括置換や依頼語の件数を合否基準にせず、構造・操作・状態・条件と結果を説明する文にしています。日本語はです・ますを保ち、停止時の確認、油の回収、安全な作業経路の確保など、目的のある依頼は残します。

## 日本語の例

| 対象 | 修正前 | 修正後 |
| --- | --- | --- |
| コークス炉の底面 | コークス炉用レンガを3×3に並べ、底面を作ってください | コークス炉用レンガを3×3に並べた層が底面になります |
| 配線 | 低圧ワイヤーの束を持ち、最初の端子、次に継電器を右クリックしてください | 低圧ワイヤーの束で端子、継電器の順に右クリックすると接続します |

| 精製機の触媒 | 画面の触媒枠へ手動で入れてください | 画面の触媒枠への投入は手動です |

「回らない場合は車輪の空間と水流、軸の接続を確認してください」「稼働中のドラムには近づかないでください」は、対処や危険回避の目的があるため保持しています。英語も単なる命令形の連続から、構造や動作結果の説明へ整えています。独立した原文レビューで、発酵槽の英語から抜けかけた液体パイプによる精製機への接続方法を戻しました。

本体の6章（はじめに2、電力5、冶金3、搬送3、加工6、トラブルシューティング1）を維持します。実アイテムのW、全コース、標準タグ、前後移動、戻る履歴、他ガイドのコンテキスト所有確認の実装は変更していません。今後アドオン教材を追加する場合は、実在する各アドオンを別の有効な標準章に分け、未導入教材と空章を除外します。

## 検査と範囲

字幕の改行単位数、語順と条件、数字、正式名称と既存の翻訳案の扱いを確認します。色指定は言語ごとに維持・再評価し、句点省略と完全な文の区切りを保持します。読む時間は各改稿後の単位から既存の `GuideCaptions.duration` で計算されます。

独立レビューで、形成位置・操作する側・右クリック・完成後の端子・対応燃料・受電可能条件・独立した燃料製造経路・材料の役割・要約の内容を照合しました。正式訳がある中国語・韓国語・トルコ語などへ誤って翻訳案を付けず、公式訳のない名称は元の英語名と提案訳を保持します。意味を直した後に全体の解説口調も確認し、名称の復元で旧命令文へ戻った箇所も再修正しています。

ヒンディー語の高炉形成説明は、長い正式名と提案訳を含む2単位から、短く完結した4単位へ作者が推敲しました。ハンマー、側面中央、右クリック、模型と実ワールドの区別を保持し、4単位を個別にNORMALへ指定します。マレー語の圧搾機の底面も、正式名と提案訳を含む各部品の配置を別の完結文にし、4単位から5単位へ推敲してすべてNORMALへ指定しました。初回の実フォント検査でベトナム語の同じ底面説明に4行の単位を1件検出したため、併記していた2部品をそれぞれ所在が分かる完結文に推敲しました。意味と部品名の限定レビューに成功し、こちらも4単位から5単位、すべてNORMALとしています。フォント幅による実行時の切断ではありません。他の長い形成説明も完全な文のまま短縮しました。数値の意味は保持し、韓国語の「다섯→5」（五層）と、ベトナム語4箇所の「4→Bốn」（四つ）の表記差は意味を照合しました。

改稿後の実際の単位に合わせ、インドネシア語のプレス機の配置／コンベア方向、韓国語とヒンディー語の独立した燃料製造／先行電力／始動の助言、マレー語の高炉材料／対応燃料／製品の色を明示し直しました。単位数が一致するだけで意味の分類も正しいとは扱わず、他言語の添字は流用していません。

安い構造・参照・翻訳・色指定・コンパイル検査の後、今回の文章を全22言語の実フォントで再検査しました。前回の句点除去だけの証拠は、新しい語句の行数証明に使いません。他プロジェクトの取得済みグリフ幅は草稿の予備確認に限り、フォント構成の一致が証明されていないため最終証拠にしません。検証クライアントは共有排他 `Local\PonderSeriesValidation` を使い、全言語の実幅・不足字形・アラビア語の整形をまとめて確認しました。最終の [結果JSON](validation-0.1.4.json) は `passed: true`、全7,936字幕単位は最大3行です。今回取得したIE自身の実グリフ幅も、以後の安い草稿確認用に出力しました。
