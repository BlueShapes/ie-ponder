# 文を途切れさせない字幕（0.1.3）

共通要件19・20・66・67に従い、幅や行数で文を別の吹き出しへ切る処理を撤去しました。字幕の原本は従来と同じキーに保ち、文字列内の改行を作者が選んだ表示境界として使います。原則は1表示につき短く完結した1文です。空き幅を理由に複数文をまとめません。

通常の折り返しは同じ吹き出し内で行います。最小320×240 GUIでも180pxを確保し、原文・各言語の訳文を最大3行、できれば2行に推敲します。幅が足りない入力を受けても文の途中を切ったり内容を省略したりせず、制作時の検査で修正対象として報告します。

## 原本の表示単位

例えば `fluid_pipes_0` の日本語は次の2文を順に表示します。

```text
液体のパイプは、入力された液体を接続先へ運びます
タンクに接続するだけで、自動的に吸い出す装置ではありません
```

旧処理は1文目を「液体のパイプは、入力された液体を」のように途中で切ることがありました。新処理ではこの1文を一つの吹き出しに保持します。

長い材料列挙も文章から直します。`arc_furnace_0` の英語は、従来の161文字の1文を次の完結した説明・指示に書き直しました。

```text
This is an assembly model of the Arc Furnace
Begin the 5×5 base with Steel Sheetmetal and slabs, as shown
Also place the steel blocks and scaffolding shown
Add the Heavy Engineering Block and Cauldron in their marked positions
```

5×5、全材料、模型であること、表示位置に従うことを保持しています。`arc_furnace_6` では電極の挿入と、消耗・手動交換の説明を別の完結文にしました。`refinery_6` ではこの版の標準バイオディーゼルに硝石の粉が必要なこと、手動投入、触媒を消費しないことを各文で保持しています。

翻訳の境界は各言語で選び、英語の単語位置を流用しません。例えばドイツ語の `coke_oven_1` は「中央層に9個を加える」「中央も空洞にしない」「合計27個」をそれぞれ完結した文で表示します。名称が長い場合も、正式名、または英語名と明示した仮訳を削って短くしません。

## 作者が指定する継続

どうしても長い文で自然な節を継続する場合、文字列の改行で境界を指定し、前の末尾と次の先頭に `…` を付けます。

```json
"text": {
  "ja": "応力が供給量を超えると…\n…つながった装置はすべて止まります",
  "en": "If stress exceeds the available capacity…\n…all connected machines stop"
}
```

これは形式を示す回帰テスト上の例であり、IEにCreateの応力システムがあるという教材ではありません。3段以上は中間の先頭と末尾の両方に記号を付けます。孤立した記号、前後不一致、続きの欠落、不自然な主語・助動詞直後の切断を検査します。文中の句読点としての `…` だけでは表示を切り替えません。通常の短文に記号を増やす必要はありません。

## 再生・検索・検査

各単位は独立した読む時間を持ち、同じステップのキーフレーム、輪郭、材料画像付き吹き出しを保持します。アラビア語は論理順の原文を保ち、字形変換後の実幅で同じ吹き出し内を折り返します。検索では改行を空白として扱うため、表示境界をまたぐ語句も検索できます。

`testCaptionUnits` は依存のないJavaコードで境界・継続回帰テストと全22言語・3,080字幕の構造検査を行い、リソース生成前にも実行します。略語、版番号1.21.1、小数、レジストリID、CJK句点、ヒンディー語・アラビア語、長い単語を含めます。全文を再連結できることだけで合格にせず、作者が定義した単位、継続記号の対応、1単位内の複数文も検査します。0.1.3から通常の文末句点は省きますが、主語や助動詞だけで終わる断片の検査は残します。意味・文法の判断は原文と各言語のレビューで補います。

実フォントと描画は `tools/run-validation.ps1 -Captions` を使い、共通排他の中で22言語を読み込みます。180px幅で3行を超えた単位を全件収集し、原文・翻訳の推敲へ戻します。今回の実施結果と配布物は [検証記録](verification.md) に記載します。

字幕位置はこのガイドの要素だけで調整し、標準の枠・フェード・文字描画を使います。最小GUIでは材料アイコンと下部の操作欄の間に置き、大きなGUIでも標準配置の曲率によって左端へはみ出さないようにします。本文と180px幅を変えない配置修正は `-Layout` で代表3場面・3種類のGUIサイズを確認できます。
